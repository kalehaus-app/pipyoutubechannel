# Metadata Guide

## Shorts — title pattern

```
[Activity] Song with Mommy [emoji]🐻 | Healthy Habits for Toddlers | Pip | Shows for Little Ones #shorts
```

Example:

```
Wash Hands Song with Mommy 🧼🐻 | Healthy Habits for Toddlers | Pip | Shows for Little Ones #shorts
```

Keep titles **boringly literal**. A parent must know exactly what the video is
in one glance. Avoid clever, punny or vague titles — they lose to obvious ones.

## Long-form — title pattern

Lead with the recognisable adventure, keep Pip's name in it:

```
Pip's Water Park Fun Day 🌊🐻 | Fun Story for Toddlers | Shows for Little Ones
```

The title must answer "what will my child see?" without the viewer guessing.

## Description format

For Shorts:

1. Literal hook — one line restating what happens
2. Short explanation — why it is fun / what habit it builds
3. `🎵 Sing along:` followed by the lyrics, when useful
4. Subscribe mention: `@showsforlittleones`
5. Appropriate hashtags

For long-form, add a one-paragraph story summary after the hook so the
listing reads like an episode rather than a clip.

## Tags

About 20, all genuinely relevant. Include:

- the episode-specific phrase (e.g. "wash hands song")
- toddler songs
- nursery rhymes
- kids songs
- sing along
- preschool songs
- healthy habits for toddlers (when relevant)
- Pip
- Shows for Little Ones
- wholesome kids cartoon

Do not stuff unrelated keywords.

## TikTok

Usually one or two short emoji-forward lines.

Common tags — use only those that genuinely match the video:

```
#toddler #toddlersoftiktok #nurseryrhymes #kidssongs #healthyhabits #pip #showsforlittleones #momsoftiktok #toddlerlife
```

## Thumbnail thinking

Even though thumbnails are produced separately, choose one scene during
planning that would make a readable thumbnail: big subject, clear emotion,
obvious activity, minimal clutter. Note it in `episode.md`.

Never copy another channel's thumbnail composition.
